# A股复盘看盘 Web 应用

基于《复盘工具API接口文档.md》梳理的公开行情接口实现的网页版看盘工具。
后端纯 Python 标准库（零第三方依赖）；前端基于 jQuery 3.7 + Bootstrap 5.3 深色主题，
ECharts 5 绘制专业 K 线（全部框架已本地化到 `static/vendor/`，无 CDN 依赖）。

## 启动方式

1. 双击 `启动.bat`，浏览器自动打开 `http://127.0.0.1:8765`
2. 或命令行运行：`python server.py`

停止：关闭黑色命令行窗口即可。

## 个股 K 线弹窗（专业级）

点击任意表格中的股票行，弹出该股详情：

- **周期切换**：分时 / 日K / 周K / 月K（前复权）
- **日K**：K线 + MA5/10/20/60 均线 + 成交量副图 + 底部缩放条 + 滚轮缩放
- **分时**：价格线 + 均价线 + 昨收基准线 + 成交量
- **十字光标**：悬停任意 K 线即显示该日 日期/开/收/高/低/涨跌幅/成交量/MA 值
- **实时行情条**：现价、涨跌幅、今开、昨收、最高、最低、换手、量比、振幅、成交额、PE/PB、市值、涨跌停价
- 红涨绿跌配色，深色专业主题

## 分页说明

全市场按每页 50 条分页，底部支持页码跳转；点"下一页"时按钮会短暂禁用并显示加载提示。
数据源偶发限流时后端自动换主机重试，若仍为空可稍候再点一次。

## 交易日历（自动过滤周末/节假日）

- 节假日数据来自公开接口 [timor.tech](http://timor.tech/api/holiday/year/2026)（无需密钥），
  拉取成功后落盘 `trade_calendar.json`，下次启动离线可用；接口不可用时降级为仅周末判断
- **自动回退**：周末/节假日打开页面，所有日期相关面板（涨停板/涨停池/炸板池/跌停板/破板/龙虎榜）
  自动定位到最近交易日查询，无需手动改日期；跨日时自动重新定位
- **日期选择器**：点击各面板的日期框弹出交易日历，周末和法定节假日置灰不可选，
  调休补班日（绿点标记）照常可选，节假日名称直接标注在日历上
- 龙虎榜默认显示上一交易日（盘后发布），其余面板默认最近交易日

## 文件说明

- `server.py` — 后端：接口代理 + 跨域解决 + TTL 缓存 + 数据归一化 + 交易日历 + 静态资源服务
- `index.html` — 前端骨架：页面结构与弹窗 DOM（不含样式与逻辑，全部外链）
- `static/vendor/` — jQuery 3.7.1 / Bootstrap 5.3.3 / Bootstrap Icons 1.11.3（本地化，无 CDN 依赖）
- `static/css/app.css` — 深色主题样式（对齐 Bootstrap 变量、面板/表格/弹窗/日历动效）
- `static/echarts.min.js` — ECharts 5.5.1 本地化，K 线渲染引擎
- `static/js/utils.js` — 工具函数：转义/格式化/请求封装/通用表格渲染（含排序、行点击K线）
- `static/js/panels.js` — 13 个面板加载器与分页逻辑
- `static/js/kline.js` — 个股 K 线弹窗（分时/日K/周K/月K + MA 均线 + 十字光标）
- `static/js/calendar.js` — 交易日历弹层（周末/节假日置灰、调休补班标记）
- `static/js/main.js` — 入口：Tab 构建、时钟与交易状态、自动刷新调度
- `trade_calendar.json` — 节假日缓存（首次拉取 timor.tech 后落盘）
- `启动.bat` — 一键启动
- `test_server.py` — 接口自检脚本（可选）
- `复盘工具API接口文档.md` — 全部接口的原始文档

## 说明

- 行情接口均为公开数据源，仅供个人学习研究使用
- 龙虎榜/竞价封单在收盘后发布，盘中显示前一交易日数据
- 顶部可开关自动刷新（15/30/60 秒），切换面板按需加载
