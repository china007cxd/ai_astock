| T+1 | 今天买的股票明天才能卖，隔日预测因此格外重要 |
| 涨停板/炸板 | 单日最多涨10%；盘中触及涨停后回落收盘=炸板，多空分歧标志 |
| 北向/沪股通资金 | 经港股通流入A股的外资，俗称"聪明钱" |
| 主力资金 | 超大单+大单交易者（机构/大户），相对散户有信息优势 |
| 龙虎榜 | 涨跌幅/换手异常时交易所公示的前五大买卖席位 |
| 换手率 | 当日成交量占流通股本比例；40%=流通筹码一天换两成五 |
| 量比 | 当日成交力度÷过去5日均量；本股连续天量，量比已非关键 |
| MA5/MA20 | 5日/20日平均价；价格远高于均线=乖离过大易回归 |
| MACD/KDJ | 趋势金叉指标/超买超卖指标，>80为超买 |
| 融资余额分位 | 借钱买本股的规模处于历史什么水平；90%分位=杠杆情绪极值 |
| 封单 | 涨停板上排队未成交的买单，越大越稳固 |
| 乖离率(BIAS) | 价格偏离均线的百分比，+50%属极端，通常以横盘或急跌修复 |
| 盈亏比 | 预期盈利÷预期亏损，>1.5 才值得出手 |
| 置信度 | 本次分析的可靠程度，取决于数据完整性与信号一致性 |

## ⚠️ 风险提示与免责声明

### 硬性止损规则（若参与必须遵守）
- **技术止损**：跌破 15.50 无条件止损
- **幅度止损**：亏损超 -3% 无条件离场（T+1 下次日开盘执行）
- **时间止损**：3 日内未创新高或量能萎缩，离场

### 特别风险警告
- ⚠️ **高波动题材股**：本股近 10 个交易日内出现 ±7% 以上单日波动 4 次，次日 -5% 甚至逼近跌停（14.18）完全在正常波动范围内
- ⚠️ 公司已于 9/2、9/19、9/22 三次发布异常波动/风险提示公告，主业亏损（PE为负），股价由厄尔尼诺叙事驱动，**叙事证伪或板块退潮时缺乏基本面托底**
- ⚠️ 若明日大盘继续缩量、医药/AI 抽血效应延续，高位股补跌风险加大
- ⚠️ 若突发监管核查（严重异常波动认定/停牌核查），流动性将瞬间冻结
- ⚠️ 本报告基于公开信息与量化模型，不构成投资建议

### 置信度说明
🟡 **中置信度**：个股行情/资金/龙虎榜/公告数据完整且多源交叉验证；缺失隔夜外围行情、当日分时级主力精确净额，MACD/KDJ 为形态推断。若上述缺口数据偏空（外围大跌/分时主力净流出），结论将进一步向看跌倾斜。

### 模型局限性
