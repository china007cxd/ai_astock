# 交易纪律与错误自查清单

作者用真金白银（多次月度亏损创新高）换来的教训。**任何复盘和操作建议都必须对照本文件。** 语言直接犀利，对事不对人。

---

## 一、铁律（盘前必读，逐条遵守）

1. **只做模式内交易**。不符合选股/买点模式的一律不做——模式外的亏钱最伤、最没必要。
2. **管住手**。机会没有了就没有了，宁可空仓也不随手单。「随手单」「急于回本乱作」是亏损首因。
3. **追随赚钱效应，避开亏钱效应**。明知是亏钱方向绝不碰。
4. **允许小亏，不能大亏**。该止损坚决止损，绝不幻想。
5. **不追涨**，除非确认强度；涨超 3 个点的票不追，以低吸为主。
6. **冰点期不格局**。有利润先保住本金，弱势里万一判断错就是补跌。
7. **量化市场，冲高即止盈机会**。不报绝对龙头就别恋战。
8. **环境优先于战法**。大盘太差时，龟兔、蛇形都会失效——先看环境再谈出手。
9. **不接飞刀、不接退潮期的盘**。集合竞价走坏直接走。
10. **越弱势越报团**。要么最强龙头，要么空仓，不碰中位股。
11. **市场永远是对的**。走势再意外也要认，别和市场赌气。
12. **骄兵必败**。低吸赚了别炫耀，骄傲会消耗运气、导致乱作。

## 三、盘前自查表（开盘前）

```
盘前检查：
- [ ] 隔夜外盘（美股/日韩）与相关期货方向？对今日情绪偏多还是偏空？
- [ ] 昨日赚钱效应方向今日是否延续？亏钱效应是否扩散？
- [ ] 当前情绪周期在哪个阶段？（冰点/回暖/高潮/分歧/退潮）
- [ ] 今日有没有符合我模式的票？没有就准备空仓
- [ ] 我的自选票竞价表现如何？弱转强还是走弱？
- [ ] 今天的仓位上限是多少？环境差就轻仓/空仓
- [ ] 我现在的状态：是否急于回本？是否骄傲？（情绪不对就不做）
```

## 四、盘后自查表（收盘后）

```
盘后检查：
- [ ] 今天的操作是否都在模式内？模式外的单为什么做？
- [ ] 对照「高频错误清单」17 条，今天踩了哪几条？
- [ ] 买卖点是否执行了纪律？有没有幻想/追高/不止损？
- [ ] 赚钱/亏钱效应判断对了吗？有没有做反方向？
- [ ] 情绪周期定位准不准？明日会如何演绎？
- [ ] 明日策略：方向 + 标的 + 买点条件 + 卖出计划
- [ ] 一句话总结今天最大的教训
```

## 五、心态纪律（作者反复自省）

- **求稳**：时间/本金有限时，先把心态拉回正轨，稳字当头。
- **预判 > 应对**：作者自省「所有短线都没有预判的本事，都是盘中做应对」——盘前就要想好剧本，盘中只做执行，不临时起意。
- **不报复性交易**：连续亏损后最容易乱作，此时应减仓或空仓冷静。
- **认亏不认命**：单笔亏损要认，但体系要持续打磨（审美、筹码、分时理解）。
- **责任驱动**：作者以家庭责任（买房、父母期望）自勉——控制风险、保重身体，不让情绪毁掉本金。
