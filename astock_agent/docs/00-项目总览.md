# 00-项目总览（`src/astock_agent/__init__.py`）

## 职责

Python 包的入口文件。它的存在让 `import astock_agent` 成为可能，
并在此处放了一份"项目导览"——包结构清单和核心流程说明。

## 内容

- `__version__ = "0.1.0"`：包版本号
- 模块 docstring：项目一句话介绍、核心流程、包结构清单

## 谁依赖它

- 任何 `from astock_agent.xxx import ...` 的导入都会先执行这个文件
- 子模块用相对导入 `from . import config` 时也会触发

## 修改注意点

- 此文件没有逻辑代码，改它主要是更新导览说明
- `__version__` 如需随版本升级，注意与 `pyproject.toml` 里的版本保持一致
