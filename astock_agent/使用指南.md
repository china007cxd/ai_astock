# A股选股 Agent 使用指南

## 1. 概述

A股选股 Agent 是一个帮助你把选股经验（案例截图 + 文字描述）提炼为结构化规则、并自动执行筛选的工具。核心理念：**案例是数据、规则是产物，运行时只做确定性执行**。

- 截图只在离线学习时被 AI 视觉模型解读一次，运行时不做图形判断
- 选股条件分两条路：能用东财智能选股自然语言查的（如"MACD金叉"）走查询；需要数据计算验证的（如"筹码集中度<15%"）走验证
- 每次运行针对一套模式，手动触发，结果包含每只股票命中了哪些条件

## 2. 安装与启动

### 前置条件

| 项目 | 说明 |
|---|---|
| Python | 3.10+，已安装 uv 包管理器 |
| astock 看盘服务 | 端口 8765，提供数据接口（与本项目在同一目录的 `..\astock\`） |
| DeepSeek API Key | 文本模型 `deepseek-chat` + 视觉模型 `deepseek-v4-flash-vision-exp`（学习案例时使用，选股运行时不需要） |

### 配置

1. 进入 `astock_agent/` 目录
2. 复制 `.env.example` 为 `.env`
3. 在 `.env` 中填写 `DEEPSEEK_API_KEY=你的key`（DeepSeek 官网获取，约 2 元/百万 token）
4. 其他配置项一般无需修改（模型名、端口等已预设）

### 启动

**方式一：双击 `启动.bat`**（推荐）
> 自动检测 astock 是否运行 → 未运行则拉起 → 启动 agent → 打开浏览器

**方式二：手动启动**
```bash
# 1. 先启动 astock（8656 端口）
cd ..\astock && python server.py

# 2. 再启动 agent（8766 端口）
cd ..\astock_agent && uv run uvicorn astock_agent.main:app --host 127.0.0.1 --port 8766
```

浏览器打开 **http://127.0.0.1:8766**，顶部状态栏显示 `astock: 已连接` 和 `LLM: 已配置Key` 即就绪。

## 3. 界面概览

页面顶部有四个标签页：

| 标签 | 用途 |
|---|---|
| **模式管理** | 新建/删除模式、上传案例（截图+说明）、触发学习 |
| **学习确认** | 审查 AI 提炼的草案、修改条件、确认保存为正式规则 |
| **选股运行** | 选模式 → 运行 → 查看结果表格 |
| **历史记录** | 查看历次运行结果 |

## 4. 模式管理 —— 组织的你的选股逻辑

### 4.1 新建模式

每套选股逻辑一个模式（如"MACD金叉启动"、"涨停回马枪"）。在顶部输入框输入模式名，点击「新建模式」。

### 4.2 上传案例（核心步骤）

案例是 AI 学习的唯一素材，质量直接影响提炼效果。

**案例结构约定**：
```
cases/模式名/
├── 案例01_20260820低吸点/
│   ├── 截图1.png          # 任意多张，PNG/JPG/GIF/WebP
│   ├── 截图2.png          # 命名随意
│   └── 说明.md            # 文字描述
└── 案例02_20260818突破/
    ├── 日线图.png
    └── 说明.md
```

**截图要求**：
- 包含你判断该股票的软件界面截图（K线图、均线、MACD、筹码分布、资金流等）
- 截图上有标注/箭头更好，AI 视觉模型会识别图中标注文字
- 图片不要超过 20MB/张

**说明.md 要求**（风格不限，以下两种均可）：
```markdown
# 条件清单风格
1. 日线MACD在零轴上方金叉
2. 5日、10日、20日均线多头排列
3. 主力净流入为正，且连续3日净流入
4. 筹码90%成本集中度 < 15%
```

或写成叙事复盘风格（AI 同样能理解）：
```markdown
# 叙事复盘风格
2026年8月20日发现该票，MACD刚完成金叉且红柱持续放大，
均线系统多头排列，5日线回踩不破。筹码显示低位密集，
获利盘已达70%，主力资金持续流入。当天放量突破前高。
```

**建议每套模式准备 3-5 个案例起步**，越多越准。

### 4.3 上传操作

1. 左侧点击要上传的模式
2. 在右侧上传区 **拖拽截图文件** 到虚线框，或点击虚线框选择文件
3. 填写案例名（如 `案例01_20260820低吸点`）和 说明.md 内容
4. 点击「上传案例」

上传后可在页面查看案例列表和截图预览。

### 4.4 触发学习

案例上传完成后，选中模式，点击「**学习规则**」按钮。

> 学习过程：AI 视觉模型解读每张截图 → 文本模型综合所有案例归纳条件 → 生成草案 → 与已有规则对比（增量学习时）→ 等待你审查确认

进度条会实时显示当前阶段（截图解读 / 规则提炼 / 对比已存规则）。完成后提示「请到学习确认页审查」。

## 5. 学习确认 —— 审查并确认规则

### 5.1 加载草案

切换到「学习确认」标签，选择模式，点击「加载草案」。

### 5.2 审查要点

页面展示：
- **模式基本信息**：名称、概述、组合方式（intersection 取交集 / union 取并集）
- **差异对比**（增量学习时）：新增/修改/删除/不变的条件数，点击展开可见详情
- **条件清单**：每条条件可编辑

### 5.3 条件编辑

每条条件有两种类型：

| 类型 | 说明 | 示例 |
|---|---|---|
| **query** | 东财智能选股自然语言查询 | 查询语句：`MACD金叉`、`主力净流入大于0` |
| **verify** | 数据工具逐只验证 | 选择验证函数 + 填写参数 |

**query 条件**：保持查询语句简洁，一条查询一个核心条件。东财智能选股对复杂语句解析能力有限，如"MACD金叉且主力净流入"不如拆成两条。

**verify 条件**：从下拉菜单选择验证函数，参数会自动填入默认值，可修改。例如 `profit_ratio_gt` 默认 `{"threshold": 70}` 表示"获利盘高于70%"。

**操作按钮**：
- 「添加条件」新增一条
- 「上移/下移」调整顺序（不影响结果，仅便于阅读）
- 「删除」移除该条件
- 「保存草案」仅保存修改，不生效
- 「确认保存为正式规则」草案变为正式规则，可在选股运行页使用
- 「丢弃草案」删除当前草案

> 点击「确认保存」后，该模式即可在「选股运行」页使用。

## 6. 选股运行 —— 执行筛选

### 6.1 运行

1. 切换到「选股运行」标签
2. 下拉选择模式（仅显示已确认规则的）
3. 点击「开始选股」

### 6.2 运行流程

```
执行查询条件（并行）→ 取交集（或并集）→ 逐只验证 → 生成命中说明
```

- 进度条显示实时阶段和日志
- 查询条件并行调用东财智能选股（每条最多返回 100 只）
- 验证条件用 8 并发逐只校验（避免打爆 astock 服务）

### 6.3 结果解读

结果页包含：
- **条件命中卡片**：每条查询条件命中多少只
- **股票表格**：
  - 代码 / 名称 / 现价 / 涨跌（红涨绿跌）
  - 命中条件标签（绿色 = 命中 / 红色 = 未通过 / 灰色 = 验证失败）
  - 说明（AI 生成的一句话总结，无 AI Key 时用模板生成）

### 6.4 交集为空怎么办

如果所有条件取交集后为空，页面会显示黄色提示框，列出各条件各自命中数，例如：
> 各条件交集为空（「MACD金叉」命中81只、「主力净流入>0」命中100只、「筹码集中度<15%」命中23只）。说明当前市场没有同时满足所有条件的股票，可考虑放宽某条条件。

建议：回到「学习确认」页，放宽某条过于严格的条件（如筹码集中度阈值从 15% 调到 20%），重新确认后重跑。

## 7. 历史记录

每次运行结果自动存档为 `runs/时间_随机id.json`。历史记录页按时间倒序列出，点击任意行可查看完整结果。

## 8. 校验函数速查

> 学习确认页编辑 verify 条件时，从下拉菜单选择函数，参数按默认值自动填入。

| 函数名 | 功能 | 默认参数 |
|---|---|---|
| `macd_gold_cross` | 近N日内MACD金叉 | `{"lookback": 3}` |
| `macd_dead_cross` | 近N日内MACD死叉 | `{"lookback": 3}` |
| `ma_bull_alignment` | 均线多头排列(MA5>10>20>60) | `{}` |
| `ma_bear_alignment` | 均线空头排列 | `{}` |
| `price_above_ma` | 收盘价站上MA(n) | `{"n": 20}` |
| `pct_gain_range` | 近days日累计涨幅在[lo,hi]区间 | `{"days": 5, "lo": -100, "hi": 100}` |
| `new_high_n_days` | 收盘价创n日新高 | `{"n": 60}` |
| `vol_shrink_break` | 放量突破前高 | `{"shrink_n": 5, "break_n": 20, "vol_mult": 1.5}` |
| `chips_concentration_lt` | 90%筹码集中度低于threshold | `{"threshold": 15}` |
| `profit_ratio_lt` | 获利盘比例低于threshold | `{"threshold": 30}` |
| `profit_ratio_gt` | 获利盘比例高于threshold | `{"threshold": 70}` |
| `avg_cost_near_price` | 现价与平均成本差距在pct%内 | `{"pct": 5}` |
| `in_hot_plate` | 所属板块在热门概念榜前top_n | `{"top_n": 20}` |
| `in_plate_flow_top` | 所属板块在板块主力资金榜前n | `{"n": 20}` |
| `main_net_gt` | 主力净流入大于value(元) | `{"value": 0}` |
| `main_net_lt` | 主力净流入小于value(元) | `{"value": 0}` |

## 9. 增量学习

当你积累了新的案例后：

1. 把新案例文件夹丢进对应模式目录
2. 在「模式管理」页再次点击「学习规则」
3. AI 会综合所有案例（新旧一起）重新提炼规则
4. 学习确认页会展示**新旧差异**（新增了哪些条件、删除了哪些、修改了哪些）
5. 审查后确认合并

每次增量学习都基于全部案例归纳，不是简单的追加，AI 会重新判断哪些条件仍然有效。

## 11. 常见问题

| 问题 | 原因/解决 |
|---|---|
| 顶部显示「LLM: 未配置Key」 | `.env` 中 `DEEPSEEK_API_KEY` 为空，填写后重启服务 |
| 顶部显示「astock: 未启动」 | 先运行 `..\astock\启动.bat`，或直接用一键 `启动.bat` |
| 学习按钮点击后报错「无案例」 | 该模式下还没有案例文件夹，需要在模式管理页上传截图+说明.md |
| 学习任务失败 | 查看页面进度区的日志；确认 DeepSeek Key 有效且余额充足 |
| 选股运行时提示「未确认规则」 | 该模式只学习了但未在「学习确认」页点「确认保存为正式规则」 |
| 选股结果交集为空 | 所有条件同时满足的股票不存在，结果页各条件命中数提示放宽方向 |
| 某条查询条件返回空 | 东财智能选股可能无法解析该查询语句，尝试简化或改为 verify 条件 |
| 页面加载慢/样式异常 | 清除浏览器缓存（Ctrl+F5），确认 agent 服务未报错 |
| 端口 8766 被占用 | 修改 `.env` 中 `AGENT_PORT` 为其他端口，重启 |
